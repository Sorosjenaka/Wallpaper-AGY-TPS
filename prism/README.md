# Patch Reasoning Effort untuk Obsidian Prism

**Obsidian Prism** dibuat oleh **RMvdesi**. Patch oleh **0XSoros** ini ditujukan untuk revisi `7cc059d5b549410cee3e9d70bc8577b3f21b1a06` dari rilis `v1.0.8-beta.2`. Patch memakai GPL-3.0-only. Mode opsional di Wallpaper-AGY-TPS memasang source Prism ke direktori plugin tersendiri. [Source Prism di revisi tersebut](https://github.com/RMvdesi/obsidian-prism/tree/7cc059d5b549410cee3e9d70bc8577b3f21b1a06)

Perubahan utama mencakup transform knob dan isian pada jalur drag, jeda efek bintang selama drag, pemulihan ketika tangkapan pointer lepas, dan tes regresi. Installer Kit membuat file `.kit-hide-storage-popup` di direktori plugin Prism agar pengingat otomatis Memory & Conversation DB Guard tidak muncul. Integrasi ini dikelola oleh Wallpaper-AGY-TPS sebagai distribusi komunitas.

File [patch](reasoning-effort.patch), [GPL-3.0](LICENSE), [NOTICE](NOTICE), dan [lisensi pihak ketiga](THIRD_PARTY_NOTICES.md) disertakan bersama sumber upstream yang dipatok di atas. Atribusi slider upstream juga diberikan kepada LLYSH-HANNARI.
